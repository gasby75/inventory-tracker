Inventory Tracker

This project is a simple inventory tracking system built with TypeScript and object-oriented programming.

Features

- Physical and digital products
- Product inheritance
- Tax calculation
- Product details
- Discountable product interface
- Bulk discounts for physical products
- Sorting products by price
- Sorting products by name
- TypeScript type safety
- Object-oriented programming concepts

Technologies Used

- TypeScript
- Node.js
- npm

OOP Concepts Used

- Inheritance
- Encapsulation
- Abstraction
- Polymorphism
- Interfaces

How to Run

Install dependencies:

npm install

Compile the TypeScript:

npx tsc

Run the program:

node dist/main.js
